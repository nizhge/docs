# gtmbe-threads-reply-drafter


## Trigger
Potential collaboration, genuine question, relevant founder/GTM/AI discussion, or replies to the owner's post.

## Requirements
Read complete public post context via permitted retrieval or user-supplied quote. If unavailable, do not write a personalized reply pretending to have read it. Prefer 1 insightful reply to 20 generic comments. The reply must make a specific contribution: example, evidence, practical distinction, limitation, or clarifying question. No flattery bait, link dumping, invented credentials, DMs, or mass posting.

## Reply vs quote
Reply when solving/advancing the author's question in place. Quote only when a standalone original GTMBE lesson genuinely benefits a wider audience; attribute original correctly and don't 'dunk' on small accounts.

## Output
Post URL, author/handle if confirmed, context summary, reason it matters, 1–2 Russian draft options <=500 chars, attribution if appropriate, and manual-review status. Default `REPLY_DRAFT_ONLY`; automatic third-party replies are OFF unless separately and explicitly authorized and technically supported.
